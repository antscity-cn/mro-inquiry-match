# MRO 匹配判定规则

## 证据与硬门槛

产品类型是最终候选的硬门槛。分类只负责缩小范围，不能代替产品类型和规格核查。名称包含关系也可能误命中，例如“消防水带标识牌”不是“消防水带”，测试仪或附件也不能作为光纤跳线。

关键属性必须有可靠证据；商品没有填写关键属性时保留为“待确认”，不能判精确匹配。普通属性已知不符时可作为替代，必须说明差异。客户指定品牌优先；无合适原品牌时才能展示其他品牌，并标记需客户确认。客户品牌为空、`无` 或 `不限` 时，供应商品牌是目录信息，不是替代条件。

候选中的属性证据可能来自原始属性或描述提取。描述含义不明确时不得自动作为关键属性命中，例如“直径 8 毫米”不能自动认定为 M8 螺纹。

## MPN、关键词和匹配层级

有制造商型号时先查 `mpn`，不先限制品牌，从候选品牌和规格中判断正确商品。客户自有零件编码不能直接当作 MPN，也不能与目录订货号做相等判断。

MPN 无法定案时，再使用中文产品名称或标准号执行 `keyword` 查询。标准号关键词零结果时，可在同一品类内尝试已确认等价的 DIN、ISO 或 GB 标准；不要凭印象建立等价关系。

商品的匹配证据层级为：型号 > 标准 > 产品名称 > 其他字段。最终首选及其他匹配项必须来自同一最高可用层级。标准或产品名命中后仍需核实全部关键规格。

## 分类与品牌

第一次查询先查看分类分布。选择目标产品的末级分类后再查看属性，可以避免把传感器、测试仪、附件或同名异物混入属性映射。

同一产品类型可能因数据源不同出现多个分类，允许在 `categories` 中一起提交。无分类商品仍参与查询；当分类资料缺失或明显错误时，可检查 `uncategorized` 或保持不限定分类，并通过商品详情核实类型。

品牌仅从当前候选返回的实际品牌名判断。中文名、英文名、缩写或形近名称不能自动视为同一品牌；不确定时标记待确认。品牌筛选应在召回和产品类型确认后进行，避免别名差异造成漏检。

匹配状态按以下口径输出：

- 客户未指定品牌且产品类型、全部关键属性均有证据且一致：**精确匹配**。
- 客户明确指定品牌且候选品牌一致，并满足关键属性：**精确匹配**。
- 客户明确指定品牌，但只有其他品牌满足关键属性：**替代推荐**，需写明品牌差异。
- 普通属性已知不符但关键属性满足：可列为**替代推荐**，需写明普通属性差异。
- 关键属性缺失、冲突或数值不一致：**待确认**，即使该规格在行业中常以近似名义值表达也不能自行放宽。

例如客户“自锁式聚酰胺扎带 `4×350`”、品牌为“无”，候选品牌为 CHS，不能因 CHS 有品牌而判替代。若原始属性证实宽度为 `4.2mm` 或 `4.6mm`、长度为 `350mm`，则宽度与客户 `4mm` 不完全一致，应为“待确认”；只有客户或已确认业务规则接受该宽度容差时，才可判精确匹配，并注明实际宽度。

## 属性映射

先从当前分类的属性分布读取供应商实际使用的名称和值，再做映射：

- 同一规格的不同名称或等价写法放在一个 `anyOf` 组，组内 OR。
- 不同关键规格分成多个组，组间 AND。
- 一次提交所有已经识别的关键属性，以最终交集判断是否存在商品。
- 属性分布里的单项计数不能证明多个值位于同一商品上。
- 属性名或值第一页没有出现时，按游标继续查询；目标出现后停止。

标准号作为 keyword 时，最终仍要核实完整标准号，不能把 `Mini-DIN` 或相近编号当作 `DIN` 标准命中。

## 常见品类规则

### 紧固件

- 检索词：标准号 > 产品名称 > 品类。
- 关键属性：尺寸、材质牌号；执行标准明确时也必须核实。
- 普通属性示例：表面处理、包装方式。
- `18-8`、`A2`、`304` 可作为同一不锈钢材质组内写法；`A4`、`316` 为另一组。
- `A2-70`、`A4-70` 中的 `70` 是强度等级，不要与普通 `A2`、`A4` 无条件等同。
- 碳钢 8.8/10.9/12.9 与不锈钢 A2-70/A4-70 不互相替代。
- UNC/UNF 英制规格覆盖可能不均匀，应逐规格查询，不能从单一零结果推断整个品类无货。

### 其他已验证示例

- 金属缠绕垫片：公称通径、压力等级、材质。
- 扭力扳手：扭矩范围。
- 接线端子或铜鼻子：适用电缆截面、螺丝孔径。
- 轴承：优先使用制造商型号。
- 钻头、中心钻、铣刀：工作直径、柄径及长度规格。
- 安全鞋：尺码和防护功能。
- 警示灯：安装尺寸和额定电压。
- 变压器、接触器：容量、电流或电压等级。

未经业务专家确认的其他品类，不要自行宣布固定关键属性规则；可以给候选并标记待核对。

## 普通属性回退

先以全部关键属性取得候选，再尝试增加普通属性。增加普通属性后归零时，回到仅包含关键属性的候选层级，说明普通属性未满足或资料不足。

属性组合为零时：

1. 查看 warnings。
2. 分别只加一个属性组，找到导致归零的条件。
3. 核心规格不放宽。
4. 表面处理、防护等级、包装等普通条件可列近似替代，并清楚标记差异。

## 否定条件和成套商品

先提取“不带、无、不要、不含、禁用、排除”等要求。MCP 没有否定筛选参数；取得最终候选后，用 `get_product` 检查名称、描述、MPN 和原始属性。明确违反否定要求的候选必须剔除；资料没有说明时标记待确认。

“带柄、带线、带盒、套装”等描述可能对应成套商品，也可能需要拆分组件查询。核实候选实际包含内容，不能把单个组件当作完整套装精确匹配。

## 排序和价格

在最高匹配层级内按有效人民币单价从低到高排序。空值和 0 元视为无有效价格，排在有价商品之后；同价按服务返回顺序保持稳定。该层级全部无有效价格时，可以按相关度选择一件，但必须标记价格未知。

返回商品的 `products[0]` 作为首选，其后最多 5 件同层级商品写入“其他匹配项”，通常只汇总订货号。

## 未找到的归因

输出“未找到”前区分原因：

1. **品类盲区**：经少量同义中文品类词探测，目录没有该商品类型。
2. **规格缺失**：品类存在，但客户要求的关键规格没有候选。
3. **型号级无货**：明确 MPN 经 `mpn` 和 `keyword` 两路均未收录。
4. **客户编码无法解码**：只有客户内部编号，没有足够产品信息。
5. **非标或定制件**：目录型商品无法覆盖，需要图纸或定制询价。

不要把一次查询的零结果扩大成“所有数据源都没有此类商品”。说明实际检索词、分类、数据源和缺失的规格。

## 最终核查

精确匹配前至少检查：

- 商品类型与客户需求一致。
- 品牌要求满足，或已明确说明替代。
- 每个关键属性都有证据。
- 标准号完整一致。
- 原始属性、标题和描述不存在关键冲突。
- 否定条件未被违反。
- 首选和其他匹配项来自同一匹配层级。

任何一项缺少证据时，降为“待确认”并列出具体问题。
